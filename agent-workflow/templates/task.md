# Optional scope format

Use only if a written scope is useful and the host does not already supply it.
Depends on [reading](../topics/reading.md). This is not a planning procedure,
board, state transition, branch convention or approval-token contract.

## Scope
Expected behavior, context and affected boundaries/files.

## Inputs
Authoritative requirements, existing implementation/design and required contracts.

## Reads
Concrete applicable guidance and product context; required dependencies included.
Read before affected implementation. Do not replace concrete paths with router names.

## Non-goals
Explicit changes that are outside this scope.

## Acceptance
Observable behavior and required verification, including applicable manual checks.

## Results
Delivered changes, exact files, actual check outcomes, omissions and remaining risks.
