# Inventory

One independently selectable bundle, with local dependencies and no automatic
cross-bundle activation. The declaration is the complete installed-file inventory.

| File | Role / when to read |
| --- | --- |
| [ENTRY.md](ENTRY.md) | Short scope, invariants, applicability and navigation |
| [Design](topics/design.md) | Tokens/components/layout/platform; requires entry |
| [Accessibility](topics/accessibility.md) | Contrast, targets, states, motion/dark mode; requires design and entry |
| [Handoff](topics/handoff.md) | Final specifications/review; requires design and accessibility |
| [References](references.md) | Optional unresolved standards questions, local policy first |
| [NOTICE.md](NOTICE.md) | Provenance, changes and exclusions |
| [LICENSE](LICENSE) | Full Apache-2.0 terms |
| `guidance-bundle.json` | Schema-1 entry/file/notice declaration |

No runtime, third-party skill/data, generator, product branding or concrete product
API is installed. This is design guidance, not automatic accessibility enforcement.
