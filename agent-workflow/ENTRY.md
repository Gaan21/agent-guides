# Agent workflow

For agents and developers working on an assigned scope. This bundle governs
reading, evidence and review, not planning, task creation or runtime installation.

## Always

- Read project/worktree authority and applicable local instructions first. Preserve
  security, ownership, stack contracts, existing work and explicit exceptions.
- Before applicable edits, read required preloads and relevant guidance with its
  dependencies. Reuse content still in context; consult new topics as work changes.
- Use the same retained source, selection, engine, policy and overlay identity for
  implementation and review. Never independently resolve latest or edit live snapshots.
- Factory mechanisms own tools, branches, validation, review and publication. Do
  not add another branch, tool pipeline, reviewer, result file or Git step.
- Manual work keeps the agreed branch. After successfully validated closure,
  perform scoped commit/push without another prompt, unless repository instructions
  or host protections require separate authorization. No unrelated staging,
  blanket staging, release, merge, deployment or activation is implied.
- A missing or failing mandatory check blocks closure and commit/push: report it
  and consult the owner or existing host blocked-work mechanism. Do not bypass guards.
- Keep output concise: changed behavior/files, actual checks and remaining risks.
  Distinguish evidence from claims; do not disclose secrets or customer data.

## Read when relevant

| Work | Required local detail | Dependencies |
| --- | --- | --- |
| Start implementation, change scope, lose context, or propose a snippet | [Reading](topics/reading.md) | This entry; applicable project/stack authority |
| Validate, encounter a failed check, or close work | [Validation](topics/validation.md) | This entry; actual required checks |
| Independent review requested or offered | [Review](topics/review.md) | Reading and validation; supplied change set and acceptance |
| An optional written scope is useful | [Scope format](templates/task.md) | Reading; not a task lifecycle |

Advice-only work does not create branches, run unrelated product checks or publish
changes. Selecting this bundle does not select every stack or install tools. Its
availability does not prove native loading or model compliance.
