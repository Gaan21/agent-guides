# Optional references

Read the local applicable topic first. These links support unresolved questions;
they do not replace local tokens, stack contracts, adopted policies or product context.
Use file and section names for local navigation, not fragile anchor requirements.

## Conditional comparison contract

When an accessibility or external-design comparison is requested or performed:

1. For context, read the affected local UI/testing instructions first; preserve patterns,
   tokens, stack/product authority and the agreed change scope.
2. Compare the relevant official criteria, not an imported checklist or an external
   default design. References remain technical support, not final authority.
3. Record actionable findings with justified high/medium/low severity and the
   scoped delta, including any systemic proposal, before adoption. State differences
   and proposed changes rather than silently replacing local decisions.
4. Reuse existing host evidence: no second factory report, pipeline or consumer-written
   central register. Factory owns assignments, checks, review and closure.

This conditional contract does not require web consultation on every UI patch.
Exploration remains optional; no third-party body, tool or installation is required.
