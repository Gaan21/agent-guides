# Inventory

One independently selectable bundle; no cross-bundle dependency mechanism.
The declaration lists all installed files; this inventory describes their roles.

| File | Role / when to read |
| --- | --- |
| [ENTRY.md](ENTRY.md) | Short always-applicable authority and navigation |
| [Reading](topics/reading.md) | Implementation/snippet/scope/context change; requires entry |
| [Validation](topics/validation.md) | Checks/blocked work/closure; requires entry and reading |
| [Review](topics/review.md) | Requested/accepted independent review; requires reading and validation |
| [Scope format](templates/task.md) | Optional scope/inputs/reads/non-goals/acceptance/results; requires reading |
| [NOTICE.md](NOTICE.md) | Provenance, changes and exclusions |
| [LICENSE](LICENSE) | Full Apache-2.0 terms |
| `guidance-bundle.json` | Schema-1 entry/file/notice declaration |

Not a task planner, Git tool, review service or loader. No runtime configuration,
external skill, tutorial, product-specific contract or historical report is installed.
Selecting it does not prove a model reads or follows its instructions.
